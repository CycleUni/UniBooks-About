# 等待清單

察覺你想要的那本書還沒被人貼上？到貨通知來幫你自動追蹤。

## 等待清單是什麼？

等待清單是一套自動書籍訂閱機制。若你搜尋到的書目尚無賣家上架，即可「先訂閱」它。
當將來有人刊登這本書時，平台會立即發送通知，使你最快能夠行動。

## 如何訂閱

1. **找到你想買的書** — 在搜尋頁或書單中挑選目標。
2. **點擊「通知我」** — 於書籍畫面點此按鈕即可。
3. **確認** — 系統記錄等待狀態，開始為你追新。

完全不需要重複輸入，幾秒鐘內搞完。你可同時訂閱多本書，無上限。

## 「N 人等待中」

每一本書的頁面會信顯示當前等待者的人數（字母 N）。
- 人我數越多，這本書的搶手度越亮項。
- 它用來**激勵賣家上架**：已經有閒置這本書的學生得到了「有需求」的美感資訊，更易放下猶豫賣出。

## 收到到貨通知

有人刊登出你訂閱的書後，系統會立即寄信到你 .edu.tw 信箱。
包含：
- 書名
- 書況（上一/良/有註/損）
- 價格
- 賣家學校
- 一鍵到達書籍頁面的客製化連結

> 信箱來通知就夠了，不需刷頁面。收到通知快一度點入，稀有的書籍扛得不行。

## 我的訂閱操作

在「個人頁面」→**「我的訂閱」**中可一次查看、移除不再需要的訂閱條目。

## 收到通知後的行動

- **不要猶豫** — 全等待組都 Chaque 同一時間接到通知。
- **書況不完美？** 來看平台上候補的下一賣家，不必勉強接手。
- **結同校面交更快** — 單用平台聊天計畫約學校面交，等到最快的接觸 feat。

認為易校校網通知改善時機，搶第一手。
