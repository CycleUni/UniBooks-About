# 關於我們

CycleUni 易校網是一個專為台灣大專院校學生打造的**二手教科書搜尋與媒合平台**。

## 我們的使命

台灣的大學生每學期都在重複同樣的困境：必修課的指定教科書一本上千元，用一學期後就堆在書架上。上 Facebook 社團、Dcard 找學長姐賣的二手書，卻總是淹沒在貼文洪流中。賣書的人不知道誰在找這本書，買書的人等不到有書的人來找他們。

CycleUni 的誕生，就是為了解決這個問題。我們用 **ISBN 書目結構化資料庫**把同一本書的所有賣家聚合在一個頁面上，讓搜書、比價、聯繫都只需要幾分鐘。

## 核心價值

### 📚 以書為中心，而不是以賣場為中心

一般的電商平台都是一件商品一個頁面。但在教科書這個品類，學生的需求是「找到這本書，比較所有的賣家」。CycleUni 以每一本書為獨立單位建立搜尋頁面，同一本《微積分（第 8 版）》無論有幾個賣家在出手，都聚合在同一頁即完成比價，一頁找到最適合你的書況和價格。

### 🔔 「書還在等主人」— 到貨通知

你想要的書目前還沒有人刊登嗎？點「通知我」，當有人上架時你第一個知道。書目頁還會公開顯示「N 人在等這本書」，讓持有二手書的人暸解需求，主動上架。

### 💵 零費，面在咫尺

同校同學之間的面交交易**完全免費**。平臺不向買賣雙方抽成或收上架費。聊一聊、走一走、見個面，對面交接。

如果你需要跨校交易，平台也提供選用的價金保管服務（綠界／藍新），離校不近但安心交易不跑空。

### 🎓 學生給學生，edu.tw 信箱是入場證

我們用 .edu.tw 學信箱進行身份驗證，並在每個學期重新核驗。在這裡的每一個使用者都是真實的在學生（或經確認畢業的 alumn）。這保證了校園經濟圈信任的基礎。

### 📋 書況公開透明

賣家上架時從四級書況勾選：全新、無筆記、有劃記、有破損，並可上傳實際照片。照片一留痕，讓買家一眼看清楚真實狀態，減少認知落差。

## 為什麼只做教科書？

二手書的搜尋和匹配有著特殊的結構——用 ISBN 可以做極強的書目聚合效果。一個專注於教科書的平台才能真正把這件事做到極致；若想包山包海管服飾、寢具與器材，會犧牲掉「搜尋效率」這一核心價值。

## 團隊背景

CycleUni 由一群來自資訊背景的大學生組成，最後在讀過大學、經歷過一學期又一學期「學長，你有這本書嗎？」之後，決定用自己的軟體開發技能做出這個平台。

技術棧包括了 **Angular**（前端）、**Django**（後端），目前託管於 Cloudflare Pages 和 Vercel。開放原始碼可在 GitHub 上直接閱讀。

## 網站原理

1. **搜尋** — 在首頁以 ISBN、書名、課程或教授姓名即時找到想找的書
2. **比價** — 同一本書的所有賣家聚合在一張頁面
3. **到貨通知** — 當下沒人刊登，點一下下方「通知我」，有人刊登後自動寄信通知
4. **聯繫** — 透過平台內建工具直接聯繫賣家
5. **面交** — 約時間地點，校園裡安全面交
6. **成交確認** — 提書核對後 app 內確認，賣方獲通知、訂單結束
