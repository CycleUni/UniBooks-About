# 常見問題 FAQ

我們彙整了使用者最常問到的問題。如果未列出你的疑問，歡迎透過 GitHub 或即將上線的客服信箱聯繫我們。

---

## 一般問題

### 1. 什麼是 UniBooks？

UniBooks是一個專為台灣大專院校學生設計的二手教科書搜尋與媒合平台。我們以 ISBN 為核心建立標準化書目資料庫：同一本書的所有賣家會聚合在單一書目頁上，學生可透過 ISBN、書名、課程名稱或教授姓名精準搜尋，一頁比較所有在售書況與價格。

### 2. 使用 UniBooks 需要收費嗎？

**不需要。** 同校面交交易完全免費，平台不對買賣雙方收取上架費、手續費或任何隱藏費用。

### 3. 沒有帳號可以瀏覽嗎？

可以。任何人都可以直接瀏覽 UniBooks 頁面並搜尋及查看所有書籍內容，完全不需要登入或註冊。登入（需要 `.edu.tw` 學信箱驗證）只在你想使用刊登書籍、與賣家私訊，或啟用「到貨通知」時才需要。

## 帳號與身分驗證

### 4. 為什麼一定要使用 .edu.tw 信箱？

要使用刊登、私訊賣家等功能，必須先驗證你的 `.edu.tw` 學校信箱。這確保了平台上的每位使用者都是「真實在學生」——有效減少假冒身份、虛假刊登和陌生騷擾，建立起校園內的交易信任。

### 5. 畢業後還能繼續使用嗎？

可以。你的帳號不會被刪除，但身分會標示為「校友」。部分功能可能受到限制（例如某類校內專屬頁面），但你仍可隨意瀏覽原有書目和收到收件通知。

### 6. 每學期都需要重新驗證嗎？

是的。平台每學期會請用戶重新驗證學用郵件一次，以確保「在學生」身份的持續有效性。每次重驗證亦會更新你的狀態，保持社群指數的高度可用性。

## 刊售書本

### 7. 如何刊登賣書？

1. 點按「刊登」按鈕，輸入書籍的 ISBN。若書籍無 ISBN,你可手動輸入書名與資訊。
2. 系統會從書目庫自動帶入書名、作者、版本等詳情。
3. 從四個書況等級擇一選取（全新／無筆記／有畫記／有破損），讓買家快速了解。
4. 上傳你想要輔助的實物照片，並填寫售價（若為 0 元贈書則填寫 0）。
5. 按下「上架」即可——刊登成功後，你的書會立刻顯示在搜尋結果。

### 8. 可以設定 0 元贈書嗎？

**可以。** 價格即填 0 元，你的書就會標示為「贈送」。0 元贈書在搜尋結果中正常顯示，同校面交方式讓贈送自然的更快，平台不收任何費用。

### 9. 如何決定賣價？

參考同書、各賣家的價格與你的書的具體書況比較。通常二手教科書落在原價 **3 折至 7 折**區間。有註記或破損的可以再低一些。

## 購買與到貨通知

### 10. 什麼是「到貨通知」？

進行尋书時，平台的書目頁上若沒有任何賣家上架此書，可以點按「通知我」輸入自己的資料。一旦有使用者刊登此書，你第一時間會收到推送至 `.edu.tw` 信箱的郵件告知——以省去反覆搜尋。

### 11. 「N 人在等這本書」表示什麼？

每個書目頁會公開顯示當前「通知我」功能中登錄的使用者人數。數字越高，代表買的需求也大，這會變成激勵：有這本書的同學會知曉有很多人渴望它，加快決定上架。

### 12. 收到電腦通知之後怎麼做？

信中字樣會包含所附書名、書況、價格、賣家資訊及站調查連結。點擊連結直達該書籍頁面，便可馬上私訊賣家聯繫方式進行問交。

## 交易安全

### 13. 交易安全嗎？

你分別在兩種狀況下進行交易，保障有不同：

- **校內面交**：約定校內人多之處碰面用平台內建聊天功能就算溝通；平台這安全性由你們的聰明交易履歷保證。建議的場所：圖書館前、學生會中心、全家或有監視場所區。
- **跨校交易**：買家收到貨後享有 **72 小時**檢測期，期間沒有爭議該交易即確立。整個流程中，平台不經手現金。

### 14. 是在交易過程中受到影響怎麼辦？

任何書頁上方都支援一鍵檢舉。團隊會在內人工審核。**注意警告不實或濫使用檢舉回報**可能導致帳號停權。

## 平台政策

### 15. 我的個人資料如何處理？

你的學校身分資訊可能用於推送與你校區相關的廣告內容（如證照考試、英文書等）。但此類推送必須先取得你的同意才會進行——你隨時可以選擇退出。你的個人身分資料**絕不會未經你同意而對外分享。**

詳見 [隱私權聲明](/about/privacy)。

### 16. 書況分級標準是什麼？

賣家列出時都須從四個等級中選一個並回附明晰的真實照片：

| 等級 | 說明 |
|---|---|
| 全新 | 完全未拆、無書寫、無摺痕 |
| 無筆記 | 閱讀溫柔、內頁中無記號 |
| 有劃記 | 存少量字畫線但全文依然完好 |
| 有破損 | 較明顯缺頁、水傷或斑損，影響判讀 |
